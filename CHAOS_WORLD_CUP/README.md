# CHAOS WORLD CUP

빨강·노랑·초록·파랑 네 팀이 스스로 판단해 점령, 전투, 수정 운반, 타워 방어, 보스 공략, 본진 기습을 수행하는 모바일 우선 자동 관전형 PWA입니다. 외부 라이브러리·CDN·이미지·음원·백엔드가 필요하지 않습니다.

## 바로 실행

ES Module과 Web Worker를 사용하므로 `index.html`을 파일 앱에서 직접 여는 대신 정적 웹 서버 또는 GitHub Pages에서 실행하세요.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

- 기본 경기: `http://localhost:8080/`
- 빠른 검증 경기(75초): `http://localhost:8080/?fast=1`
- 자동 밸런스 검사: `http://localhost:8080/?fast=1&benchmark=12`

## 실제 구현 기능

- 80×80, 100×100, 120×120 시드 기반 대칭 보정 격자
- 팀당 24~40개, 총 96~160개 유닛
- 러너, 파이터, 가디언, 레인저, 엔지니어, 서포터 6병과
- 전략 AI와 5개 분대: 영토, 수정, 타워, 보스, 코어, 방어, 선두 견제, 재집결
- BFS 흐름장 캐시, 장애물 회피, 아군 간격 유지, 체력 기반 후퇴
- 영토 영향력, 중립 타워 5개, 중앙 수정의 실제 획득·낙하·탈취·반납
- 본진 보호막·본체 파괴, 타워 공격, 엔지니어 방벽과 수리, 서포터 회복·보호막
- 거대 골렘, 전기 구체, 흡수 슬라임, 공중 감시자 보스 유형
- 피해 기여도와 마지막 공격을 함께 반영하는 보스 점수
- 이동 요새 통제·호위
- 15개 경기 규칙과 AI 우선순위의 실제 연동
- 중력, 홍수, 정전, 타워 초기화, 보스 난입, 망령, 포털 폭주, 운석, 지도 분단, 외곽 붕괴, 이동 요새, 에너지 폭풍
- 선두 현상금, 선두 견제 작전, 후반 목표 배율로 자연스러운 추격 기회
- 단일 실제 사건 객체를 공유하는 중계, 큰 자막, 카메라, 슬로모션, 통계
- 중요 전투 밀도와 사건 중요도를 따르는 자동 카메라
- 드래그, 핀치, 더블 탭, 유닛 탭 추적
- WebGL2 격자 텍스처, 포인트 인스턴스식 일괄 렌더링, GLSL 세계 효과
- WebGL2를 못 쓰는 환경의 Canvas 2D 폴백
- WebAudio 합성 효과음과 경기 단계별 절차 음악
- 일시정지, 1/2/4배속, 전체 지도, 자동 감독, 팀 추적, 경기당 카오스 3회
- 결과 점수 그래프, 팀 통계, 실제 활약 기반 개인상, 주요 사건 요약
- `localStorage` 누적 기록·설정 저장과 손상 데이터 폴백
- 결과 11초 뒤 새 시드 경기 자동 시작 및 무한 반복
- 서비스 워커 오프라인 캐시와 설치형 PWA
- 저성능 감지, DPR 상한, 자동 렌더 해상도 조절, 파티클 상한
- WebGL context lost 복구, 백그라운드 계산 폭주 방지
- FPS, TPS, 전략, 흐름장 캐시, 유닛 수를 보는 선택형 디버그 패널

## GitHub Pages 업로드

1. ZIP을 풀고 `CHAOS_WORLD_CUP` 안의 파일 전체를 GitHub 저장소의 공개할 폴더에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 브랜치와 폴더를 선택합니다.
3. GitHub가 표시한 HTTPS 주소를 엽니다. 하위 폴더에 올려도 상대 경로로 작동합니다.
4. 새 버전을 올린 뒤 예전 화면이 남으면 브라우저를 완전히 닫았다 열거나 사이트 데이터를 한 번 지웁니다.

## PWA 설치

### iPhone / iPad Safari

1. GitHub Pages의 HTTPS 주소를 Safari에서 엽니다.
2. 공유 버튼을 누릅니다.
3. **홈 화면에 추가**를 선택합니다.
4. 홈 화면의 `Chaos Cup` 아이콘으로 실행합니다.

### Android Chrome

1. GitHub Pages 주소를 Chrome에서 엽니다.
2. 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.

첫 터치 전에는 모바일 자동 재생 정책에 따라 무음으로 진행됩니다. 화면 오른쪽 위의 음표 버튼이나 아무 조작을 한 뒤부터 합성 음향이 활성화됩니다.

## 동작 원리 요약

`simulation-worker.js`가 20 TPS의 고정 간격으로 `Simulation`을 계산합니다. 전략 AI는 2.5초마다 점수, 규칙, 목표, 선두, 본진 위험을 평가해 팀 작전과 분대 목표를 갱신합니다. 유닛은 캐시된 흐름장을 따라 이동하면서 근거리 회피, 전투 거리, 후퇴, 호위, 병과 능력을 적용합니다. 메인 스레드는 상태 스냅샷을 보간해 렌더링하고 UI, 터치, 카메라, 파티클, 오디오만 담당합니다.

## 현재 제한 사항

- 모바일 브라우저의 메모리와 발열을 고려해 동시 유닛은 최대 160개로 제한했습니다.
- 경기 종료 하이라이트는 최근 사건의 중요도 순 장면을 결과 카드와 점수 그래프로 재구성합니다. 전체 전장 상태를 영상처럼 되감는 리플레이는 저장하지 않아 장시간 실행 시 메모리 증가를 막았습니다.
- 파괴 가능한 벽은 운석과 보스 공격, 임시 엔지니어 방벽의 수명으로 변화합니다. 모든 일반 투사체가 벽에 개별 물리 충돌하는 방식은 아닙니다.
- iOS는 브라우저 정책상 진동 API를 제공하지 않을 수 있으며, 그 경우 진동만 자동 생략됩니다.
- 서비스 워커와 설치 기능은 HTTPS 또는 localhost에서만 활성화됩니다.
