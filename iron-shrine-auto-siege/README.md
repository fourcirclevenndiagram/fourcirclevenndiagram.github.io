# IRON SHRINE: AUTO SIEGE

세로형 모바일 화면을 위한 자동 플레이 픽셀아트 전략 시뮬레이션입니다. 외부 이미지·폰트·라이브러리 없이 작동하며, 저해상도 Canvas 2D 전장을 WebGL 셰이더로 확대·합성해 CRT 스캔라인, 비네트, 색수차, 글로우를 더합니다.

## 관전 목표

- 중앙의 **IRON SHRINE**을 지키면서 4개의 외곽 릴레이를 점령합니다.
- 릴레이가 충전한 코어 에너지가 100%가 되면 승리합니다.
- 러너, 센티널, 랜서, 메딕은 각자 역할에 맞춰 이동·전투·치유합니다.
- 7종 일반 적과 보스 **VOID HERALD**가 웨이브로 침공합니다.
- 전투 AI는 전황에 따라 `ASCEND / BASTION / REAPER` 전술을 자동 선택합니다.
- 라운드가 끝나면 5초 뒤 다음 섹터가 자동으로 시작됩니다.

## 관전자 조작

- 화면 아래 `ASCEND`: 11초 동안 점령·이동 우선
- 화면 아래 `BASTION`: 11초 동안 코어 방어·피해 감소 우선
- 화면 아래 `REAPER`: 11초 동안 공격·흡혈 우선
- 화면 오른쪽 위 배속 표시: `1x → 2x → 0.5x`
- 화면 맨 오른쪽 위 `TAP/SFX/MUTE`: 사운드 활성화 또는 음소거
- 아무 조작을 하지 않아도 모든 콘텐츠가 자동 진행됩니다.

## 실행

PWA와 ES 모듈을 사용하므로 웹 서버를 통해 여세요. 이 폴더에서 다음 중 하나를 실행하면 됩니다.

```bash
python3 -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080`을 엽니다. 또는 `npm install && npm run dev`를 사용해도 됩니다. `npm run build`는 배포용 `dist/` 폴더를 만듭니다. GitHub Pages나 일반 정적 호스팅에 폴더 전체를 올려도 됩니다. iPhone Safari에서는 공유 메뉴의 **홈 화면에 추가**로 설치할 수 있습니다.

## 기술 메모

- 논리 해상도: 216 × 468
- `devicePixelRatio`: 최대 2
- 고정 60Hz 시뮬레이션, 최대 480 파티클
- WebGL 1.0 프래그먼트 셰이더 + Canvas 2D 픽셀 장면
- WebAudio 합성 효과음 및 앰비언트 드론
- Service Worker 오프라인 캐시
- `visibilitychange` 자동 일시정지
- `localStorage` 최고 점수·승패 기록
- 진동 지원 기기 판정 피드백
