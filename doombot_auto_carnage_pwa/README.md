# DOOMBOT // AUTO CARNAGE

스스로 길을 찾고, 장애물을 부수고, 5종의 적과 싸우는 관전형 WebGL 전투 시뮬레이션입니다.

## 실행

- `index.html`을 바로 열면 게임이 실행됩니다.
- PWA 설치와 오프라인 캐시는 HTTPS 또는 로컬 웹서버에서 작동합니다.
- 간단한 로컬 실행: `python3 -m http.server 8080`

## 조작

- 기본적으로 모든 이동과 전투가 자동입니다.
- 하단에서 일시정지, 전술 성향, 오버드라이브, 배속, 사운드를 바꿀 수 있습니다.
- 무기 칸을 누르면 7종 중 하나를 잠그며, 한 번 더 누르면 자동 선택으로 돌아갑니다.
- 키보드: `P`/Space 일시정지, `M` 전술 전환, `1`~`7` 무기 잠금, `R` 새 임무, `F` 전체화면.

## 전투 구성

- 적 5종: 황무지 사수, 잿불 임프, 강철 사냥개, 공허의 눈, 공성 집행자
- 무기 7종: IRON-9, TRENCH-12, RIPPER MG, VOLT LANCE, HELLROCKET, RAIL SPIKE, SUNBREAKER
- 5개 웨이브가 끝나면 새 맵과 새 임무가 자동 생성됩니다.
