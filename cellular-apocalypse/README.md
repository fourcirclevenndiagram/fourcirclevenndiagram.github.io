# CELLULAR APOCALYPSE

불·전기·식물·물이 80×80~120×120 격자 생태계에서 자동으로 번지고, 충돌하고, 환경을 바꾸며 싸우는 모바일 관전형 PWA입니다.

별도 서버, npm, 빌드 과정, 외부 라이브러리, CDN, 이미지·폰트 다운로드 없이 작동합니다. 처음 접속한 뒤에는 오프라인 실행과 홈 화면 설치를 지원합니다.

## 바로 실행하기

보안 정책상 파일을 `file://`로 직접 열면 Web Worker와 PWA 캐시가 차단될 수 있습니다. GitHub Pages에 올리거나 간단한 정적 서버로 열어 주세요.

```bash
python3 -m http.server 8080
```

그다음 브라우저에서 `http://localhost:8080`을 엽니다.

## GitHub Pages에 올리는 최소 방법

1. 이 ZIP의 압축을 풉니다.
2. `index.html`이 보이도록 모든 파일과 `icons` 폴더를 GitHub 저장소에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`를 고르고 저장합니다.
5. 잠시 뒤 표시되는 주소로 접속합니다.

기존 `fourcirclevenndiagram.github.io` 저장소에서 다른 페이지도 운영 중이라면, 이 파일들을 `cellular-apocalypse` 폴더에 넣고 `https://fourcirclevenndiagram.github.io/cellular-apocalypse/`로 접속하면 됩니다.

## 모바일 설치

- iPhone Safari: 페이지 열기 → 공유 버튼 → **홈 화면에 추가**
- Android Chrome: 페이지 열기 → 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

첫 터치 전에는 모바일 브라우저 정책에 따라 무음으로 실행됩니다. 첫 터치 뒤 합성 환경음과 사건 효과음이 활성화됩니다.

## 조작

- 한 손가락 드래그: 카메라 이동
- 핀치: 확대·축소
- 전장 두 번 탭: 전체 맵
- 전장 한 번 탭: 선택 지역 잠시 추적
- 하단 버튼: 정지, 1×/2×/4×, 전체 맵, 자동 카메라, 재난, 설정
- 데스크톱: 마우스 드래그·휠, `Space` 정지, `1`/`2`/`4` 배속

## 구현된 시스템

- 시드 기반 value noise/fBM 지형, 호수, 계곡, 토양, 광물, 암석 생성
- 셀별 높이·온도·수분·영양·전하·전도성·오염·물질량·소속·상태·수명·변화량
- EMBER / VOLT / BLOOM / TIDE 고유 자원 순환과 환경 의존 확장
- 실제 전도성·수분 경로를 이용하는 연쇄 번개
- 화염 폭풍, 과전하 폭발, 대개화, 포자 비산, 범람, 결빙·증발·재발아
- 주 코어·보조 코어·코어 파괴·재건·세력 탈락
- 상황별 자동 전략과 넓은 영토 유지 비용
- 10종 세계 재난과 경기당 3회 수동 개입
- 사건 중요도 기반 자동 카메라, 화면 흔들림, 경고 원, 짧은 슬로모션
- 실제 사건 감지 기반 한국어 중계
- 4단계 종말 수렴, 3종 승리 조건, 종합 점수
- 결과 통계, 점유율 그래프, 영토 타임랩스, 11초 후 자동 재경기
- WebGL2 셰이더 렌더링과 Canvas 2D 폴백
- 적응형 화질, 성능 표시, 10종 관찰 레이어
- WebAudio 합성 효과음·동적 환경음, 진동, 설정·누적 통계 저장
- 서비스 워커 오프라인 캐시와 설치형 PWA

## 숨은 자동 테스트

브라우저 개발자 콘솔에서 아래 함수를 실행하면 현재 경기를 잠시 교체하여, 같은 실제 셀 업데이트 엔진으로 여러 시드를 그래픽 없이 빠르게 검사한 뒤 승수와 평균 경기 시간을 출력합니다.

```js
CELLULAR_APOCALYPSE_TEST(24, 100)
```

테스트가 끝나면 원래 시드의 경기가 처음부터 자동 재시작됩니다.
