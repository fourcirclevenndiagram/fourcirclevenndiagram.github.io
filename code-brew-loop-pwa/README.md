# CODE BREW LOOP

코드를 타이핑하고, 10초 동안 검토하고, 실행 결과를 보여준 뒤, 다시 10초 동안 감상하고, 개발자가 커피를 마시는 ASCII 애니메이션으로 10초 쉬는 관상용 PWA입니다. 30개 프로그램이 끝없이 순환합니다.

## 실행

- 가장 간단한 방법: `index.html`을 브라우저에서 엽니다.
- PWA 설치와 오프라인 캐시는 HTTPS 또는 로컬 웹서버에서 작동합니다.
- GitHub Pages에 폴더 안 파일을 그대로 올리면 설치 가능한 웹앱으로 사용할 수 있습니다.

## 조작

- 재생/일시정지: 화면 아래 재생 버튼 또는 스페이스바
- 다음 장면: 화면 아래 넘기기 버튼 또는 오른쪽 화살표
- 프로그램 선택: 목록 버튼 또는 `L`
- 사운드: 스피커 버튼(기본값은 꺼짐)

모든 그래픽과 코드는 외부 리소스 없이 로컬에서 실행됩니다.
